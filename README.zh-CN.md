# Galaxy Explorer（银河探索者）

一款可玩的 3D 银河探索 / 考古 RPG。一行种子字符串即可生成一个约 1,100 个恒星系统的
银河切片；你驾驶它、降落在它的行星上、步行其上、采集你能带走的一切，并翻译那些逝去
者留下的东西——直到你能说出他们究竟遭遇了什么。

全部由静态文件运行：没有构建步骤，没有打包器，没有 CDN 依赖。Three.js 已内置在
`vendor/` 目录中。

```bash
npm start      # http://localhost:8080
npm test       # 75 个无头测试
npm run check  # 对每个源文件做语法检查
```

## 切片里有什么

| 领域 | 状态 |
| --- | --- |
| 3D 环境 | 程序化恒星系统、行星、地形、大气、星云、遗迹、空间站、异常点 |
| 摄像机 | 飞船内与步行时均可切换第一 / 第三人称（`V`） |
| 可控飞船 | 类 6DOF 飞行、加速、刹车、完全停止、消耗燃料与受航程限制的超空间跃迁 |
| 恒星系统 | 7 种恒星类型、行星类型、卫星、行星环、潮汐锁定、小行星带、危险环境、生命 |
| 行星探索 | 降落（`G`）、行走、疾跑、跳跃、采集地表矿点 |
| 天体扫描 | 目标循环切换（`Tab`）、扫描（`T`）、档案摘要、星系勘测 |
| 资源采集 | 19 种资源、货舱上限、开采产量、市场价格 |
| 飞船改装 | 14 个槽位、57 个模块、派生属性、功率预算 |
| 角色成长 | 经验、等级、8 个职业分支共 41 个技能 |
| 银河地图 | 3D 星区云、跃迁范围圈、航线预览、星系档案、点击选中 |
| 异星遗迹 | 5 个已灭绝文明、遗迹地点、遗物发掘 |
| 异星文明 | 4 个现存文化，具备对话、贸易、声望与政治 |
| 任务 | 12 个任务，含类型化目标与任务链 |
| 对话 | 受声望、能力与标志位控制的分支对话树 |
| 科技树 | 10 个分类共 55 项科技，含受遗物解锁的逆向重建 |
| 存档 / 读档 | 4 个存档位 + 自动存档 + JSON 导出 / 导入 |

此外还有把这些内容串起来的部分：银河文明档案馆、带有假设 / 确证证据链的考古日志、
重建出的时间线，以及一个永不解说过早的主线谜团（"共鸣"），共六个阶段。

| --- | --- |
| `W` `S` | 推进 / 倒退（飞船）· 前进 / 后退（步行） |
| `A` `D` | 偏航 · 侧移 |
| `Q` `E` | 横滚 · 发掘遗物（步行） |
| 鼠标 | 视角（点击画布捕获指针） |
| `Shift` | 加速 · 疾跑 |
| `Space` | 刹车 · 跳跃（步行） |
| `X` | 完全停止 |
| `Tab` | 循环切换目标 |
| `T` | 扫描目标 |
| `G` | 降落行星 / 对接空间站 |
| `F` | 返回飞船（步行）· 聚焦所选（地图） |
| `V` | 第一 / 第三人称 |
| `M` | 银河地图 |
| `R` | 被毁后重生 · 重置地图视角 |
| `H` | 燃料耗尽时请求救援拖航 |
| `E` | 太空中打捞残骸 · 步行时发掘遗物 |
| `I` `U` `K` `L` `J` `B` `A` `P` `N` | 货舱 · 飞船 · 技能 · 科技 · 考古 · 文明 · 档案馆 · 任务 · 星系图 |

## 目录结构

```
index.html  styles.css     DOM 外壳 + 界面皮肤
src/main.js  src/Game.js   入口 + 总控
src/core/                 带种子的随机数、事件总线、时钟、数据加载器、存档系统、噪声
src/world/                银河与恒星系统生成器、名称生成器
src/sim/                  12 个模拟系统（飞船、资源、技能、科技、档案馆、
                          考古、文明、任务、事件、跃迁、战斗、状态）
src/render/               着色器、对象工厂、输入、控制器、3 个场景
src/states/               状态机 + 太空 / 地表 / 地图状态
src/ui/                   通知、HUD、面板、弹窗、银河地图、主菜单、设置
data/                     11 个 JSON 内容包（所有游戏内容都在这里）
data/i18n/                界面与内容翻译（`en`、`zh`）
vendor/three.module.js    Three.js r0.160.1
tests/                    模拟、内容、界面、场景与通关测试套件
docs/                     设计文档 + 架构文档
```

所有游戏内容都是数据驱动的：新增一个文明、任务、科技、资源或事件只需要改 JSON，
并由 `tests/test_content.mjs` 校验。

## 语言与语音播报

界面支持中英双语，并且语言切换是全局的：在主菜单中选择语言或按 `F2`，HUD、面板、
弹窗、银河地图、程序化生成的星系描述、对话与任务文本会同时切换，包括当前屏幕上
已经打开的内容。字典存放在 `data/i18n/`；其中 `zh` 额外带有一个内容包，翻译了所有
资源、科技、技能、文明、遗物、任务、事件、纪元与对话条目，以及程序化生成的文案表。
如果某个键缺失、失效或未翻译，`tests/test_i18n.mjs` 会让测试失败。

`F2` 中还包含音频混音（主音量、音乐、音效、环境音）与语音播报开关：开启后，通讯内容、
遗物分析报告与任务结算会通过浏览器的语音合成引擎朗读出来。设置会跨会话保存；
关闭播报时游戏完全一样，只是安静无声。
