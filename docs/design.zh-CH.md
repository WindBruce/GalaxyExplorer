# Galaxy Explorer —— 设计

> 一款 3D 银河探索与考古 RPG。你不是某场战争的主角。你是那个从逝者留下的痕迹中
> 推断出这里发生过什么——以及正在发生什么——的人。

---

## 1. 支柱

1. **宇宙比你更古老。** 每一处遗迹、每一件遗物、每一个已灭绝文明都比玩家早数百万年。
   没有任何东西是为你而放置的。历史上没有任务标记。
2. **知识即成长。** 信用点只能买到船体；只有理解才能买到结局。科技是从异星遗物中
   *重建*出来的，而不是从商店里买来的。
3. **距离即难度。** 燃料、跃迁航程、辐射、船体完整度与敌对空域决定你能去哪里。深空
   之所以值得前往，恰恰因为它代价高昂。
4. **是关系，不是阵营。** 文明不是"人类 vs 外星人"。四个现存文化拥有真实的经济、
   战争 / 和平周期，以及随你声望变化而改变的对话。
5. **一切皆有种子。** 一行字符串生成整个银河。同一行字符串永远生成同一个银河。

---

## 2. 玩家幻想

你指挥一艘飞船和一套宇航服。你勘测恒星系统、降落行星、行走于地形之上、采集你能带走
的一切、扫描你带不走的，并把遗物带回船上翻译。经过数小时的游玩，图景逐渐拼合：一张
连接了数千个世界的量子网络、一场以恒星点火为武器的战争、一次同步的消失，以及某种
把这一切都编了目的事物——**共鸣**。

主线谜团永不解说过早。它通过六个阶段推进，每个阶段都以*已确证*的时间线事件为门槛
（`data/timeline.json` → `mystery.stages`）：

| 阶段 | 名称 | 门槛 |
| --- | --- | --- |
| m0 | 无法解释 | — |
| m1 | 遗迹有些不对劲 | `evFirstCities` |
| m2 | 那些消失是协同的 | `evVanishing`、`evNetworkBuild` |
| m3 | 一道信号早于网络存在 | `evCoreSignal`、`evSunderingWar` |
| m4 | 牧者 | `evShepherd`、`evStarKilling` |
| m5 | 共鸣 | `evShepherd`、`evCoreSignal`、`evVanishing`、`evStarKilling` |

最终揭示会重新诠释早期事件：那些"必要"的恒星灭杀（`evStarKilling`）、那道早已在等待
的信号（`evCoreSignal`）以及空荡的圣器所，都不再是谜团，而变成了*编目*。

## 3. 时间预算（目标平衡）

| 活动 | 目标 | 体现在 |
| --- | --- | --- |
| 探索 | ~30% | 星系飞行、行星降落、异常点、星区多样性 |
| 采集 | ~20% | 小行星采矿、地表矿点、打捞、市场套利 |
| 成长 | ~15% | 经验 / 等级、41 个技能、55 项科技、57 个飞船模块 |
| 文明互动 | ~15% | 对话、贸易、声望、政治、任务 |
| 战斗 | ~10% | 海盗、无人机、狂信徒巡逻队、牧者仆从 |
| 考古 | ~10% | 发掘、翻译、证据、谜团 |

战斗刻意只占少数：它的存在是为了让风险变得真实（船体、货舱、燃料），而不是为了撑起
整个游戏。每一类敌对目标都能被一艘加速的飞船甩掉；每一类敌对目标也都能终结一艘大意
的飞船。

## 4. 系统

### 4.1 银河
从银河核球到未知区域共九个星区，各有自己的配色、危险剖面与文明偏向。切片中约 1,100
个系统，由种子按对数螺旋臂生成；系统细节惰性生成，因此该结构可扩展到数百万系统
（见 `architecture.md` §4）。

### 4.2 飞行与跃迁
类 6DOF 飞行，带惯性漂移、加速、刹车与完全停止；第一与第三人称摄像机（`V`）。跃迁
航程是一项派生飞船属性；燃料消耗随距离次线性增长，因此短程跳转很便宜，而横穿银河的
跃迁是一个工程。`canJump()` 是唯一权威——地图、HUD 与任务都向它查询。

### 4.3 行星地表
程序化 CPU 噪声地形，按高度与坡度逐生物群落着色，含大气、散布的物件、资源矿点与遗迹
地点。步行为第一 / 第三人称，可疾跑与跳跃。危险是真实的：辐射、毒性与引力会啃食船体，
除非生命维持与技能抵消它们。

### 4.4 扫描
`Tab` 循环目标，`T` 扫描。扫描范围与分辨率是飞船属性；扫描一个天体可得到档案摘要、
一条档案馆记录与经验，并且是勘测任务的前置条件。异常点与遗迹有各自的扫描结果。

### 4.5 资源与经济
19 种资源，各有等级、分类、基础价格与波动率。货舱容量是飞船属性；开采产量是飞船
属性；市场价格随文明的经济剖面波动。空间站服务的船体维修定价为每点 12 ¢，燃料按
当地 `fuelPrice` 计价。

### 4.6 飞船开发
14 个槽位、57 个模块。派生属性（推力、跃迁航程 / 效率、功率输出 / 消耗、护盾与回复、
船体与回复、武器伤害 / 射速 / 射程、货舱、开采产量 / 速率、扫描范围 / 分辨率、
分析 / 翻译 / 发掘、研究、危险抗性、无人机、自动化）由配置重新计算，再由技能与科技
能力修正。过载的功率会让护盾与引擎断电。

### 4.7 角色成长
经验来自扫描、降落、击杀、发掘、分析与跃迁。每次升级给予技能点；8 个职业分支共 41 个
技能节点（探索者、科学家、工程师、考古学家、外交官、士兵、异星生物学家、AI 研究员）
会作用于飞船属性与交互概率。

### 4.8 科技
10 个分类共 55 项科技，用研究点 + 材料研发。`unknown` 分类由 `requiresArtifact` 把关：
那些科技只能通过分析正确的遗物来*重建*，而这正是让探索成为力量源泉的设计。

## 5. 考古 —— 核心循环

遗迹是历史的拼图，不是 loot 容器。

1. **找到**一处遗迹（扫描星系、降落、走到地点）。
2. **发掘**一件遗物（`E`）。它带着等级、文明标签与纪元进入日志——但没有解释。
3. 在实验室中**分析**它。成功取决于飞船的 `analysis` 与 `translation` 属性及技能。
   失败也会产出一份*部分解读*。
4. 每件遗物 `supports` 一个或多个剧本时间线事件。一件支撑遗物 = 一个**假设**；
   两件独立遗物 = **已确证的证据**。三个剧本假设刻意相互冲突，冲突的解读会一直留在
   日志中直到被解决。
5. 已确证的事件会推进谜团阶段，并可能重建一项 `unknown` 科技。

遗物还会解锁科技（`techTag` → `requiresArtifact`）、充实银河文明档案馆、并完成考古
任务。这里没有即时答案：日志是一个假设工作台，而时间线视图是由*你的*证据重建出来的。

## 6. 文明

四个现存文化，各有一份模板描述其经济、政治、对话树、物种与星区偏向：

| 文明 | 特征 |
| --- | --- |
| 地球协约 | 扩张主义、官僚化，玩家最初的参照系 |
| 维哈拉蒂 | 尚武的荣誉文化；巡守自己的空域；战争与和平都是可达状态 |
| 凯尔萨利 | 歌谣 / 档案文化；以知识与奇异物理学交易 |
| 灰烬残族 | 灾后幸存者；多疑、有用、脆弱 |

五个已灭绝文明（艾尔塞拉、辛萨里、科拉西、维沙里、牧者）只通过其遗迹与遗物为人所知。

关系动态演化：声望随对话、任务、贸易与战斗变动；它控制对话选项
（`requires.capability/reputation/flag`）、市场价格、空间站服务，以及一个星系是被宣称、
争夺还是开放。没有任何东西是二元的盟友 / 敌人开关。

## 7. 任务与事件

12 个任务，从开场的勘测（`q_firstSurvey`）到考古（`q_ruinSignal`、`q_translation`）、
文明支线（`q_veshari`、`q_kelthariSongs`、`q_perseusSurvey`）以及终局
（`q_vanishing`、`q_theQuestion`）。目标是类型化的（`scanSystem`、`collectResource`、
`analyzeArtifact`、`researchTech`、`reachRegion`、`talkTo`、`returnTo` 等），因此进度由
模拟追踪，而非由脚本追踪。

14 个动态事件是加权且受上下文限制的（在星系内、靠近遗迹、靠近黑洞、深空、有文明存在、
异常密度）。每个选项都有写好的结果与持续影响——标志位、声望、伤害、遗物、信用点。
事件是叙事时刻，不是随机掉落判定。

## 8. 深空中的风险与回报

* **燃料** —— 每次跃迁都消耗燃料；补给燃料要花信用点；烧干了意味着一次昂贵的救援拖船。
* **船体** —— 战斗、危险与降落伤害的是同一副船体；被毁损失 4,000 ¢ 和你的位置。
* **功率** —— 模块消耗功率；过载会让护盾与引擎断电。
* **辐射 / 毒性 / 引力** —— 地表暴露程度随世界而变，可由生命维持与技能抵消。
* **导航** —— 跃迁航程从根本上限制哪些星区可达；未知区域由驱动器等级与危险抗性把关。
* **敌对目标** —— 海盗、无人机、狂信徒巡逻队与牧者仆从随星区危险度缩放；赏金与残骸
  打捞正是为这份风险买单。
* **异常点** —— 高危险、高收益：异星资源与遗物储藏。

## 9. 内容编写

新增文明：写一份 `civilizations.json` 模板（对话树、经济、政治、物种）——生成器会自动
把它放进其母星区。新增任务：写一条带类型化目标的 `quests.json` 条目。新增科技：写一条
`technologies.json` 条目；用 `requiresArtifact` 加上某件遗物上匹配的 `techTag` 即可把它
挂在遗物之后。新增事件：写一条带 `requires` 上下文与选项的 `events.json` 条目。
`tests/test_content.mjs` 会校验每一个交叉引用，因此一个拼写错误会让测试运行失败，
而不是让游戏失败。

## 10. 切片范围之外的内容（以及原因）

* **多船员 / 基地建设** —— 垂直切片是一艘船、一套宇航服、一个谜团；架构（数据驱动的
  任务、文明模板、飞船槽位）就是为吸收它们而建的。
* **数十亿系统的完整银河** —— 切片内置约 1,100 个已细化系统并惰性生成；描述符格式正是
  为流式加载设计的（见 `architecture.md` §4）。
* **程序化对话文本** —— 对话是人工编写的（声音比数量更重要）；只有名称、摘要与事件
  文本是生成的。
